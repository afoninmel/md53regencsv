CSV Comparator

Upload your Beekai CSV and Power Automate CSV. The page compares shared columns and shows rows from the Beekai file that do not appear in the Power Automate file. Everything stays in the browser and reload clears all data.

No row selected.
When the row is selected, the app sends the row data as JSON via HTTP POST to the address you enter. The target endpoint must accept CORS requests from this static page.

Pro tip: If you want to compare by a specific shared column, first open the files in a spreadsheet and verify the common column names. This tool uses all columns present in both CSV files to identify matching rows.
